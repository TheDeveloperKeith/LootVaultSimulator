Earn Loot fonts are self-hosted official Fontshare files by Indian Type Foundry.

- Switzer-Medium.woff2: Switzer Medium (500). https://www.fontshare.com/fonts/switzer
- Satoshi-Variable.woff2: Satoshi variable (300–900), selected as the user-approved free sans-serif alternative to Santrio. https://www.fontshare.com/fonts/satoshi

Both retain Fontshare's license: https://www.fontshare.com/licenses
Official CSS endpoints: https://api.fontshare.com/v2/css?f[]=switzer@500&display=swap and https://api.fontshare.com/v2/css?f[]=satoshi@1&display=swap

EarnTypography.module.css applies Switzer Medium to headings and numerals, Satoshi to other text. Its digit-only Switzer face also handles numbers inside body text and button labels without splitting accessible strings.
